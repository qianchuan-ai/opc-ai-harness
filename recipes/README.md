# recipes/ 插件策展目录

按 **OPC 主理人真实使用场景 / 功能**分类，不是按痛点故事分。
每个子目录对应一类功能，内含「我亲测 `dsh plugin add` 装通过」的 dsh 插件与真实坑。

## 当前分类

| 目录 | 功能 | 插件 | 批注 |
|---|---|---|---|
| `上下文与文件引用/` | `@` 引用文件 / 目录进上下文 | dsh-at-file | ✅ 认 |
| `视觉与OCR/` | 图片 / 截图结构化解析 | modlens | ✅ 认（⚠️ Win bin 警告） |
| `试错与回退/` | 会话状态回退 | dsh-turn-rewind | ✅ 认 |
| `研究工具目录/` | 2600+ 外部接口（按事检索） | treg | ⚠️ 存疑（ingredient，需免费 token） |

## 收录纪律

- 只收**亲测 `dsh plugin add` 装通过**的插件；
- 每个插件必须带：① 是什么 ② 适配版本 ③ 真实坑 ④ 导入命令 ⑤ 谦川批注；
- 未亲测的一律进 `../logs/` 标 🕒，不进本目录；
- **不承诺「获客 / 变现」等结果**——工具只解决「已知要做什么之后怎么更省力」。
